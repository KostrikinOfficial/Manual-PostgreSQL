## 🗳️ Подзапросы
### Подзапрос - это...
SQL-запрос, вложенный внутрь другого SQL-запроса. Они позволяют использовать результат одного запроса внутри другого.

Например, найти студентов, возраст которых выше среднего:

    SELECT *
    FROM students
    WHERE age > (
        SELECT AVG(age)
        FROM students
    );

### Подзапрос в `SELECT`
Более интересный вариант, можно поместить подзапрос непосредственно в список `SELECT`, например:

    SELECT
        name,
        age,
        SELECT(SELECT AVG(age) FROM students) AS average_age
    FROM STUDENTS;

Получим примерно:
    
    name    age    average_age
    --------------------------
    Andrey  18     24.4
    David   20     24.4
    Anton   22     24.4
    Roman   45     24.4

### Подзапрос в `FROM`
Подзапрос может выступать как временная таблица, например:

    SELECT *
    FROM (
        SELECT name, age
        FROM students
        WHERE age >= 20
    ) AS adults;
