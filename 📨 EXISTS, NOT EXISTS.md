## 📨 `EXISTS`, `NOT EXISTS`
### `EXISTS` проверяет:
Существует ли хотя бы одна строка, удовлетворяющая подзапросу? Например:

    SELECT *
    FROM students s
    WHERE EXISTS (
        SELECT 1
        FROM groups g
        WHERE g.id = s.group_id
    );

Смысл: Вернуть студентов, для которых существует соответствующая группа.
### `EXISTS` не интересует данные строки
Обратим внимание: `SELECT 1`, но почему 1?

Потому что `EXISTS` не интересует конкретное значение. Ему важно только: Нашлась строка?

Есть строка → `TRUE`

Нет строки → `FALSE`
### `NOT EXISTS` полная противоположность, и означает:
Соответствующей строки не существует. Например:

    SELECT s.name
    FROM students s
    WHERE NOT EXISTS (
        SELECT 1
        FROM journal j
        WHERE j.student_id = s.id
    );

Это: Найти студентов, у которых нет записей в журнале
